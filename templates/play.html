How to join

Three minutes from the multiplayer menu to your first night. Java Edition {{ server.versions }}.

1Add the server

Open Minecraft Java Edition, go to Multiplayer, choose Add Server and paste this address. No port needed, no whitelist.

2Register on your first join

Register as soon as you spawn, you have 60 seconds. Type the same password twice to confirm it.

/register <password> <password>

For example: /register mysecretpass mysecretpass

3Set up how you log in

Premium (Microsoft) account

Link your Minecraft UUID once. Every join after that logs you in automatically, no password.

/premium

Cracked / offline account

Log in every session. Anyone can connect with your username on another client, so use a strong, unique password.

/login <password>

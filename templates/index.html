Join in three steps

Java Edition only. Bedrock, Geyser and Floodgate aren't supported.

Your account

  1. Add the server

    Multiplayer, Add Server, then paste the address. Any client from {{ server.versions }} can connect.

    {{ server.ip }}

  2. Register on your first join

    Do it straight away, you have 60 seconds. Type the same password twice.

    /register <password> <password>

  3. Link your account once

    Link your Minecraft UUID and you're logged in automatically from then on. No more passwords.

    /premium

  4. Log in every visit

    Anyone can join with your username on another client, so pick a strong, unique password. Lost passwords can't be recovered.

    /login <password>

Ask an AI without the whole server reading.

DTEmpire AI Chat gives you private AI conversations in-game. While you're in AI mode, everything you type goes only to the AI. Other players see nothing.

Run DTEmpire AI Chat on your own server

It's open source under the MIT license and works on Paper, Purpur and Folia 1.21.x with any OpenAI-compatible endpoint (LocalAI, LiteLLM, OmniRoute, or your own).

  1. Download DTEmpireAIChat.jar from the GitHub releases.
  2. Drop it into your server's plugins/ folder and restart.
  3. Set your endpoint and API key in plugins/DTEmpireAIChat/config.yml.
  4. Restart again. Players can now use /aichat.

Download the JAR Source on GitHub

Building from source needs JDK 17+ and Maven 3.9+. Never commit your API key to git.
